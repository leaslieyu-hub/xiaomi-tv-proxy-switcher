# Contributing / 参与贡献

Issues and pull requests are welcome from anywhere in the world.

欢迎来自世界各地的 Issue 和 Pull Request。

Before submitting a change, please explain the TV model, Android version, and
the behavior you tested. Do not include private IP addresses, proxy
credentials, TV backups, or personal data.

提交修改前，请说明电视型号、Android 版本和测试结果。不要提交私人 IP、代理凭据、电视备份或个人数据。

Fork the repository, make your changes, run `./gradlew assembleRelease`, and
open a pull request. Maintainers review changes before merging them into
`main`.

请先 Fork 仓库，完成修改后运行 `./gradlew assembleRelease`，再提交 Pull Request。维护者审核后才会合并到 `main` 分支。
